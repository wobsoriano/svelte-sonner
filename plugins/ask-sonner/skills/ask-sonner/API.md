# Svelte Sonner API Reference

Exact props, types, and defaults, from `svelte-sonner`'s source (`src/lib/types.ts`, `src/lib/Toaster.svelte`, `src/lib/toast-state.svelte.ts`). Options passed to `toast()` override the same options set via the Toaster's `toastOptions`.

## `<Toaster />`

| Prop                                                                              | Type                            | Default                 | Description                                                                                                                                                                                                                                                                                                                         |
| --------------------------------------------------------------------------------- | ------------------------------- | ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`                                                                              | `string`                        | –                       | Toaster id, targeted by `toast()`'s `toasterId` option. A toaster without an `id` renders only toasts without a `toasterId`.                                                                                                                                                                                                        |
| `theme`                                                                           | `'light' \| 'dark' \| 'system'` | `'light'`               | Bind to your own dark-mode state (e.g. mode-watcher's `userPrefersMode.current`) for `'system'` to actually track the OS.                                                                                                                                                                                                           |
| `richColors`                                                                      | `boolean`                       | `false`                 | Makes error and success states more colorful.                                                                                                                                                                                                                                                                                       |
| `expand`                                                                          | `boolean`                       | `false`                 | Toasts expanded by default (otherwise they expand on hover).                                                                                                                                                                                                                                                                        |
| `visibleToasts`                                                                   | `number`                        | `3`                     | Amount of visible toasts.                                                                                                                                                                                                                                                                                                           |
| `position`                                                                        | `Position`                      | `'bottom-right'`        | `top-left`, `top-center`, `top-right`, `bottom-left`, `bottom-center`, `bottom-right`.                                                                                                                                                                                                                                              |
| `closeButton`                                                                     | `boolean`                       | `false`                 | Adds a close button to all toasts, shown on hover.                                                                                                                                                                                                                                                                                  |
| `duration`                                                                        | `number`                        | `4000`                  | Default duration (ms) for toasts that don't set their own.                                                                                                                                                                                                                                                                          |
| `gap`                                                                             | `number`                        | `14`                    | Gap between toasts when expanded, in pixels.                                                                                                                                                                                                                                                                                        |
| `offset`                                                                          | `string \| number \| object`    | `'24px'`                | Offset from screen edges. Object form is per-side: `{ top, right, bottom, left }`. (The library's own JSDoc says `'32px'`; the implementation uses `24px`.)                                                                                                                                                                         |
| `mobileOffset`                                                                    | `string \| number \| object`    | `'16px'`                | Offset when screen width < 600px.                                                                                                                                                                                                                                                                                                   |
| `pauseWhenPageIsHidden`                                                           | `boolean`                       | `false`                 | Pause the toast timer while the tab is hidden, so toasts don't expire in the background.                                                                                                                                                                                                                                            |
| `swipeDirections`                                                                 | `SwipeDirection[]`              | derived from `position` | Allowed swipe-to-dismiss directions. Unset, it's the words in `position`: `bottom-right` → `['bottom','right']`, `top-center` → `['top']` (`center` isn't a swipe direction). Set it explicitly to allow others.                                                                                                                    |
| `dir`                                                                             | `'ltr' \| 'rtl' \| 'auto'`      | `'auto'`                | Text directionality.                                                                                                                                                                                                                                                                                                                |
| `hotkey`                                                                          | `string[]`                      | `['altKey','KeyT']`     | Shortcut that focuses the toaster area. Every entry must match, and each is tested as `event[entry] \|\| event.code === entry` — so an entry is either a truthy `KeyboardEvent` property (`altKey`, `shiftKey`, `metaKey`, `ctrlKey`) or a `KeyboardEvent.code` (`KeyT`). `'Alt'` matches neither and silently disables the hotkey. |
| `invert`                                                                          | `boolean`                       | `false`                 | Dark toasts in light mode and vice versa.                                                                                                                                                                                                                                                                                           |
| `toastOptions`                                                                    | `ToastOptions`                  | `{}`                    | Default options applied to every toast (see below).                                                                                                                                                                                                                                                                                 |
| `containerAriaLabel`                                                              | `string`                        | `'Notifications'`       | ARIA label for the toast container; combined with the hotkey label.                                                                                                                                                                                                                                                                 |
| `closeButtonAriaLabel`                                                            | `string`                        | `'Close toast'`         | ARIA label for the close button.                                                                                                                                                                                                                                                                                                    |
| `successIcon`, `infoIcon`, `warningIcon`, `errorIcon`, `loadingIcon`, `closeIcon` | `Snippet \| null`               | –                       | Per-type icon **snippets**, not a props object. `null` removes that icon entirely.                                                                                                                                                                                                                                                  |

`<Toaster />` also forwards any standard `<ol>` HTML attributes.

## `ToastOptions` (the Toaster's `toastOptions` prop)

| Option                                    | Type           | Description                                                                                                                                                                                                        |
| ----------------------------------------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `class`                                   | `string`       | Class applied to the toast element.                                                                                                                                                                                |
| `descriptionClass`                        | `string`       | Class applied to the description element.                                                                                                                                                                          |
| `style`                                   | `string`       | CSS string (not an object) applied to the toast element.                                                                                                                                                           |
| `cancelButtonStyle` / `actionButtonStyle` | `string`       | CSS string for the cancel/action button.                                                                                                                                                                           |
| `duration`                                | `number`       | Default duration for toasts using these defaults.                                                                                                                                                                  |
| `unstyled`                                | `boolean`      | Removes default styling — pair with `classes`/`class` for Tailwind.                                                                                                                                                |
| `classes`                                 | `ToastClasses` | Per-part classes: `{ toast, title, description, loader, closeButton, cancelButton, actionButton, icon, content }`, plus per-type keys (`success`, `error`, `warning`, `info`, `loading`) to target one toast type. |
| `closeButton`                             | `boolean`      | Show the close button.                                                                                                                                                                                             |
| `closeButtonAriaLabel`                    | `string`       | ARIA label for the close button.                                                                                                                                                                                   |

## `toast()` / `ExternalToast` options

`toast(message, options)` — `message` is a string **or a Svelte component reference** (not JSX, not `<Component />` markup, not an instance). Returns the toast's id.

| Option                                    | Type                                                  | Default | Description                                                                                                                         |
| ----------------------------------------- | ----------------------------------------------------- | ------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `description`                             | `string \| Component`                                 | –       | Renders underneath the title.                                                                                                       |
| `descriptionClass`                        | `string`                                              | –       | Class for just the description element on this toast.                                                                               |
| `closeButton`                             | `boolean`                                             | `false` | Adds a close button.                                                                                                                |
| `invert`                                  | `boolean`                                             | `false` | Dark toast in light mode and vice versa.                                                                                            |
| `duration`                                | `number`                                              | `4000`  | Milliseconds before auto-close. `Infinity` persists the toast.                                                                      |
| `position`                                | `Position`                                            | –       | Position of this toast specifically.                                                                                                |
| `dismissible`                             | `boolean`                                             | `true`  | If `false`, the user cannot dismiss the toast. (`dismissable` also works — deprecated alias.)                                       |
| `important`                               | `boolean`                                             | `false` | –                                                                                                                                   |
| `icon`                                    | `Component \| null`                                   | –       | Icon in front of the text; a component reference, `null` removes the default.                                                       |
| `component` / `componentProps`            | `Component` / `object`                                | –       | Used internally by `toast(Component, ...)` and `toast.custom(Component, ...)` to render a component as the toast body.              |
| `action`                                  | `{ label, onClick, actionButtonStyle? } \| Component` | –       | Primary button. `label` can be a string or a component. Field name is `onClick` even though Svelte markup elsewhere uses `onclick`. |
| `cancel`                                  | `{ label, onClick, actionButtonStyle? } \| Component` | –       | Secondary button; clicking dismisses the toast.                                                                                     |
| `actionButtonStyle` / `cancelButtonStyle` | `string`                                              | `''`    | CSS string for the action/cancel button.                                                                                            |
| `id`                                      | `number \| string`                                    | –       | Custom id; calling `toast()` again with the same id updates the existing toast instead of creating a new one.                       |
| `toasterId`                               | `string`                                              | –       | Id of the `<Toaster />` this toast should render in.                                                                                |
| `style`                                   | `string`                                              | –       | CSS string for the toast.                                                                                                           |
| `class`                                   | `string`                                              | –       | Class for the toast element.                                                                                                        |
| `classes`                                 | `ToastClasses`                                        | –       | Per-part classes for this single toast (same shape as `toastOptions.classes`).                                                      |
| `unstyled`                                | `boolean`                                             | `false` | Removes all default styles for this toast.                                                                                          |
| `onDismiss`                               | `(toast: ToastT) => void`                             | –       | Fires on close button, swipe, or an explicit `toast.dismiss()`.                                                                     |
| `onAutoClose`                             | `(toast: ToastT) => void`                             | –       | Fires when the toast closes automatically after `duration`.                                                                         |

## Functions

| Function                                                       | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| -------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `toast(message, opts?)`                                        | Render a toast; returns its id. `message` can be a string or a component reference.                                                                                                                                                                                                                                                                                                                                                                                                 |
| `toast.success / .error / .info / .warning(message, opts?)`    | Typed toast with matching icon.                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `toast.loading(message, opts?)`                                | Toast with a spinner; update it by id.                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `toast.message(message, opts?)`                                | Same as the base `toast()` call — explicit alias.                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `toast.promise(promise, { loading, success, error, finally })` | Loading toast that resolves with the promise. Each of `loading`/`success`/`error` is a string or a function returning a string or component reference — `loading` takes no argument, `success` takes the resolved value, `error` takes the error. A bare component reference is not accepted; return one from a function instead. `finally` runs once the promise settles either way. If the resolved value looks like a Response (`{ ok: false, ... }`), it's treated as an error. |
| `toast.custom(Component, opts?)`                               | Headless toast — pass a component reference (not JSX) plus `componentProps`; Sonner keeps its positioning/stacking/swipe behavior. The component is rendered with `componentProps` spread onto it plus a `closeToast: () => void` prop for dismissing itself.                                                                                                                                                                                                                       |
| `toast.dismiss(id?)`                                           | Dismiss one toast, or all when called without an id.                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `toast.getActiveToasts()`                                      | All non-dismissed toasts. Works anywhere, including outside a component. This is the supported way to read toast state.                                                                                                                                                                                                                                                                                                                                                             |
| `useSonner()`                                                  | **Currently unusable — avoid.** It resolves a Svelte context that `<Toaster />` sets on itself, but `<Toaster />` renders no children, so nothing is ever a descendant of it. Any call site throws `Context "<Toaster/>" not found`. Use `toast.getActiveToasts()` instead.                                                                                                                                                                                                         |

## Differences from React Sonner, if you're translating docs or examples

- One import surface either way, but Svelte-native naming: `class`/`classes` instead of `className`/`classNames`.
- No JSX. `toast(<Jsx/>)` and `toast.custom((t) => <Jsx/>)` become `toast(Component, { componentProps })` and `toast.custom(Component, { componentProps })` — always a component **reference**, never markup or an instance.
- Toaster icon overrides are **snippets** (`{#snippet successIcon()}...{/snippet}`) rather than an `icons={{ success, ... }}` prop object.
- React Sonner's `useSonner()` hook has no working equivalent — svelte-sonner exports one, but it throws from every call site (see the function table above). Reach for `toast.getActiveToasts()` instead.
- `dir` defaults to `'auto'` here vs `'ltr'` in React Sonner.
- `pauseWhenPageIsHidden` and `closeButtonAriaLabel` are svelte-sonner additions not in the classic React prop table above (i.e. not documented in most React Sonner references).
- There's no React StrictMode double-invoke to worry about; a duplicate toast in Svelte almost always means two mounted Toasters or a `toast()` call inside a re-running `$effect`.
- SvelteKit specifically needs `ssr: { noExternal: ['svelte-sonner'] }` in `vite.config.ts` — no React equivalent gotcha.
